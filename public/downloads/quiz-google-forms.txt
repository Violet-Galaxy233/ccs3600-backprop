Q1.
Q: What does the term "backpropagation" stand for?
A. Backward processing of perceptrons
B. Backward propagation of errors   [CORRECT]
C. Batch propagation of activations
D. Bidirectional propagation of weights
Points: 1
Feedback (correct): Correct. "Backpropagation" is short for backward propagation of errors. It fine-tunes the weights of a neural network based on the error rate obtained in the previous epoch. (Original slide 2)
Feedback (incorrect): The answer is B. "Backpropagation" = backward propagation of errors. The other options misuse the abbreviation. (Original slide 2)

Q2.
Q: Backpropagation is best described as a method that:
A. Defines how the computed gradient is used to update weights
B. Randomly initializes the network weights before training
C. Calculates the gradient of the loss function with respect to each weight   [CORRECT]
D. Replaces the need for a loss function during training
Points: 1
Feedback (correct): Correct. Backpropagation computes the gradient of the loss with respect to every weight; this enables each weight to be updated to reduce the loss. (Original slides 3 & 16)
Feedback (incorrect): The answer is C. Note that option A is deliberately wrong: backpropagation computes the gradient but does NOT define how the gradient is used — that is the optimizer's job (e.g., gradient descent). (Original slides 3 & 16)

Q3.
Q: In which direction does backpropagation compute gradients through the network?
A. From the first layer forward to the last layer
B. Simultaneously across all layers in parallel
C. From the last layer backward to the first layer   [CORRECT]
D. Only within the output layer
Points: 1
Feedback (correct): Correct. Backpropagation proceeds backwards — derivatives at layer N are computed first, then reused via the chain rule for layer N-1, and so on back to layer 1. (Original slides 3 & 15)
Feedback (incorrect): The answer is C. Gradients are computed from the last layer back to the first, reusing later-layer derivatives via the chain rule. (Original slides 3 & 15)

Q4.
Q: What is the defining property of a feed-forward neural network?
A. The connections between nodes do not form a cycle   [CORRECT]
B. Every node is connected back to the input layer
C. Information can flow in both directions
D. It always contains exactly one hidden layer
Points: 1
Feedback (correct): Correct. A feed-forward network has no cycles; information flows in one direction only. A network with cycles is a recurrent neural network — the opposite of feed-forward. (Original slide 4)
Feedback (incorrect): The answer is A. The defining property is the absence of cycles. Networks with cycles are recurrent networks. (Original slide 4)

Q5.
Q: In a single-layer perceptron, if the sum of weighted inputs is BELOW the threshold (usually 0), the typical output is:
A. 0
B. 1
C. -1   [CORRECT]
D. The exact value of the sum
Points: 1
Feedback (correct): Correct. In the simplest perceptron model: sum above threshold (usually 0) -> output 1; sum below threshold -> output -1. (Original slide 5)
Feedback (incorrect): The answer is C. Below threshold the typical perceptron output is -1; above threshold it is 1. (Original slide 5)

Q6.
Q: The delta rule allows a single-layer perceptron to:
A. Skip the activation function entirely
B. Compare its node outputs with the intended values and adjust weights through training   [CORRECT]
C. Convert itself into a recurrent network
D. Eliminate the need for input weights
Points: 1
Feedback (correct): Correct. The delta rule lets the network compare its outputs with the intended values and adjust weights to produce more accurate results. In multilayer perceptrons, this weight-update process is generalized as backpropagation. (Original slide 6)
Feedback (incorrect): The answer is B. The delta rule is a weight-update rule based on output-vs-target comparison. (Original slide 6)

Q7.
Q: In the multilayer feedforward formula, the input to layer i is:
A. The original network input vector x for every layer
B. The output of the previous layer (layer i-1)   [CORRECT]
C. A fresh random vector at each layer
D. The final layer's output hN
Points: 1
Feedback (correct): Correct. Each layer takes the previous layer's output as its input: h1 = f1(W1*x + b1), h2 = f2(W2*h1 + b2), and so on. Only the first hidden layer takes the raw input x. (Original slides 9-10)
Feedback (incorrect): The answer is B. Only the first hidden layer takes x; every subsequent layer takes the previous layer's output. (Original slides 9-10)

A. A sigmoid, ReLU, or tanh function   [CORRECT]
B. The bias matrix of the layer
C. The number of layers in the network
D. The input vector to the network
Points: 1
Feedback (correct): Correct. fi is the activation function of hidden layer i — sigmoid, ReLU, tanh, etc. The bias matrix (bi), layer count (N), and input vector (x) are separate symbols. (Original slide 10)
Feedback (incorrect): The answer is A. fi denotes the activation function; common choices are sigmoid, ReLU and tanh. (Original slide 10)

Q9.
Q: How does the loss (cost) function C behave?
A. Returns a high value when the output is close to the label
B. Returns a low value when the output is close to the label   [CORRECT]
C. Stays constant throughout training
D. Is only defined for recurrent networks
Points: 1
Feedback (correct): Correct. The loss is low when the network output is close to the label and high when it differs. At the start of training the loss is large; a well-trained model has a small loss. (Original slides 11-12)
Feedback (incorrect): The answer is B. Small loss = good prediction; large loss = bad prediction. (Original slides 11-12)

Q11.
Q: The weight notation w(i,j,k) refers to the weight going from:
A. Node k in layer i to node j in layer i+1
B. Node j in layer i-1 to node k in layer i   [CORRECT]
C. The bias of layer i to its output
D. The input vector directly to the output layer
Points: 1
Feedback (correct): Correct. w(i,j,k) denotes the weight from node j in layer (i-1) to node k in layer i. To minimize C, we need the derivative of C with respect to every such weight. (Original slide 13)
Feedback (incorrect): The answer is B. The indices mean: from node j (in layer i-1) into node k (in layer i). (Original slide 13)

Q12.
Q: The chain rule states that for z depending on y, and y depending on x:
A. dz/dx = dz/dy + dy/dx
B. dz/dx = dz/dy - dy/dx
C. dz/dx = (dz/dy) * (dy/dx)   [CORRECT]
D. dz/dx = (dz/dy) / (dy/dx)
Points: 1
Feedback (correct): Correct. The chain rule of calculus: dz/dx = (dz/dy)*(dy/dx). Because C depends on weights via many nested functions, the chain rule is applied recursively. (Original slide 14)
Feedback (incorrect): The answer is C. Chain rule: dz/dx is the product of dz/dy and dy/dx. (Original slide 14)

Q13.
Q: Why is the backpropagation algorithm EFFICIENT compared to computing each weight's derivative separately?
A. It ignores most of the weights to save time
B. It saves and re-uses derivative calculations from later layers via the chain rule, avoiding duplicate computation   [CORRECT]
C. It computes all layers fully in parallel with no dependencies
D. It replaces the chain rule with a single matrix inversion
Points: 1
Feedback (correct): Correct. Computing each weight's derivative separately would be extremely inefficient. Backpropagation first computes derivatives at layer N; these are ingredients in the chain-rule formula for layer N-1, so they are saved and reused — avoiding duplicate work. (Original slide 15)
Feedback (incorrect): The answer is B. Efficiency comes from reusing later-layer derivatives via the chain rule rather than recomputing them. (Original slide 15)

Q14.
Q: In the backpropagation procedure, the error at the output is computed as:
A. Desired Output - Input
B. Actual Output - Desired Output   [CORRECT]
C. Actual Output + Desired Output
D. Desired Output * Weights
Points: 1
Feedback (correct): Correct. ErrorB = Actual Output - Desired Output. The algorithm then travels back from output to hidden layers, adjusting weights to decrease this error. (Original slide 17)
Feedback (incorrect): The answer is B. The error at the output is Actual Output minus Desired Output. (Original slide 17)

Q15.
Q: Backpropagation Through Time (BPTT) handles a recurrent network by:
A. Deleting all cycles permanently from the network
B. "Unrolling" the network across time steps so it can be viewed like a feed-forward network   [CORRECT]
C. Training only the output layer and ignoring the rest
D. Converting the loss function into an activation function
Points: 1
Feedback (correct): Correct. A recurrent network has cycles, so it is not a DAG directly. BPTT "unrolls" the network — each time step is a copy — and then trains it like a feed-forward network. (Original slides 18-19)
Feedback (incorrect): The answer is B. BPTT unrolls the recurrent network in time so it can be treated like a feed-forward network for training. (Original slides 18-19)
